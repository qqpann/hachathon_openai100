# SEEDLAB — Button Garden

**教える。育てる。ひとりでできるか、試す。**

手書き数字MNISTを実際のカメラ画像から学習する小さなニューラルネットと、ロボットアームの3D育成ゲーム。Godot 4.5.1製。強化の選択をOpenAIコーチに任せると、同じアームが左の強化盤を押します。

## 起動

```sh
./prototypes/seedlab-godot/run.command
```

手動から操作を解放していく流れを、元の進行とは別に遊ぶ場合は `run-new-garden.command` を起動してください。新育成用セーブを作り、次回はその続きを読み込みます。

Godot 4.5以降とNode.js 22.12以降を使用します。ランチャーはローカルのAI接続サーバーを起動してからゲームを開きます。Godotから直接起動した場合も、ゲームがサーバーを自動起動して接続を確認します。リポジトリ直下の `.env.local` にある `OPENAI_API_KEY` はサーバーだけが読みます。キーをGodot側に入れる必要はありません。

GodotエディターのF5からも接続を自動準備します。接続が切れた場合はゲーム内の「コーチに再接続」で復旧できます。ヘルスチェックとサーバー起動はOpenAI APIを呼び出しません。手動の強化・NNの学習・試験はオフラインでも遊べます。

## 遊び方

1. **教える**：0Gから開始。左奥の手書き数字を読み、右の0〜9の3Dボタンから同じ数字をクリックしてお手本を教えます。答えのボタンは事前に点灯しません。成功なら16G以上、失敗でも5G。テーブル奥の常設モニターに、視界・12×12の入力・ニューロン・10個の数字の予測が表示されます。
2. **育てる**：机の左が強化盤。3Dボタンに重ねると効果、クリックすると購入できます。最初の「自分で押す」は学び方Lv.1、35G。SPACEでNNに1回任せる操作が解放されます。Lv.2「ひとり練習」でAによる自動練習、アームLv.1・3で2倍・3倍の切替を解放します。どの行から育てるかは自由です。
3. **試す**：「自分で押す」を購入したら、Tで10問の認定試験。学習・ランダム探索・お手本・強化を止め、練習とは別の筆跡で0〜9を一度ずつ出題し、NNの予測だけで押します。3 / 6 / 8正解でメダルと60 / 120 / 240G。報酬はカメラごとに各メダルの初回だけです。
4. **任せる**：学び方Lv.3「育成委任」を購入し、24回練習したらR。OpenAIが成績と強化盤の画像を見て、強化と理由を返します。アームがそのボタンを押し、カメラは委任前の位置に戻ります。手動の強化も続けられます。

| 操作 | 内容 |
| --- | --- |
| 右のボタンをクリック | お手本を見せる |
| Space / A | 学び方Lv.1 / Lv.2の購入後、NNに1回任せる / 自動練習 |
| 左の3Dボタン | 強化を購入。画面上の購入一覧や数字キーでの購入はありません |
| 強化にカーソルを重ねる | 内容・価格・購入段階 |
| 机の ↔ ボタン / B | 基礎研究16個 / 拡張研究8個を切替 |
| T | 10問の認定試験。終了後は練習を停止して結果を表示 |
| R | 学び方Lv.3と練習24回で解放。OpenAIへの委任を開始・停止 |
| V / C | 入力カメラを固定・手先で切替 / その視界を拡大 |
| F | 作業台の初期視点へ戻る |
| 右ドラッグ・Q/E・ホイール | 回転・距離を操作 |
| 速度ボタン / M | 購入済みの倍率（×1 → ×2 → ×3）を切替 / 消音 |
| H・Esc | 遊び方・各画面を閉じる |

試験中は10問を同じ条件で解きます。カメラの変更と強化は試験後に行ってください。遊び方を開くと、現在の動作の後で練習・試験が待機します。常設モニターを眺めている間は、ゲームがそのまま進みます。

## 強化

基礎研究は各行4段階。拡張研究が各行に2段階続きます。ニューロン追加時は既存の予測を保ち、追加分を次の経験から学習します。

| 行 | 基礎の効果 | 拡張1 | 拡張2 |
| --- | --- | --- | --- |
| ひらめき | 隠れ層8→24個 | 好奇心：28個。上位2候補が近い時、30%で2番目も試す | もう一手：32個。自動練習で失敗したら別の位置に一度再挑戦 |
| 記憶 | 復習対象32→512件 | 失敗ノート：1024件。候補3件から予測誤差の大きい経験を復習 | 成功の種：2048件。復習の1/4を成功経験から選ぶ |
| 学び方 | Lv.1：NN操作、Lv.2：自動練習、Lv.3：育成委任を解放。復習16→64回 | お手本上手：復習76回。成功したお手本の直接学習を3倍に | 苦手克服：復習88回。出題の半分を自動練習の苦手な位置に |
| アーム | Lv.1で×2切替、Lv.3で×3切替を解放。モーター速度1→2倍 | リズム：2.25倍。連続成功に最大20Pの追加報酬 | 最短ルート：2.5倍。低い軌道で移動時間をさらに25%短縮 |

価格・名前・説明は `data/upgrades.json` をGodotとサーバーで共有します。予測誤差の大きい経験には、外したボタンだけでなく、予測が低かったのに成功した経験も含みます。

## 画像とニューラルネット

**重みを持ち、誤差逆伝播でオンライン学習するMLPです。** OpenAIは強化選びを担当し、数字を読むのはローカルのNNです。

- 実際のMNISTから、各数字64枚の練習画像と16枚の試験画像（計800枚）を同梱。画像を数字フォントで代用していません。出典・元データのインデックス・チェックサムは `data/mnist/manifest.json`。
- 原本は28×28のグレースケール。紙の画面に512×512へ拡大表示し、固定カメラまたは手先カメラの **実描画512×512 → 白黒12×12** をNNに入力します。拡大によって原本の情報量が増えるわけではありません。
- **144入力 → tanh隠れ層8〜32個 → softmax出力10個**。出力は数字0〜9の予測で、合計100%です。
- 通常はNNが最も確からしいと予測した数字を押します。「好奇心」を購入すると、上位2候補が近い時だけ2番目も試します。
- 予測に正解ラベル・所持金・強化段階を渡しません。ボタンを押して採点した後に正解ラベルを教え、誤差逆伝播と経験の復習で学習します。試験では正解ラベルを学習に使いません。
- NNが選ぶのは数字のボタン。関節の動かし方は2リンクの逆運動学で制御しています。
- テーブル奥の常設モニターに、実画像・12×12入力・中間層の反応・10予測を毎秒5回表示。線は各ニューロンにつながる実際の重みのうち最も強いもの。下段は直前に正解を学ぶ前後の予測です。
- 常設表示は重み・乱数・経験・お金・現在の試行を変更しません。学習カメラには数字の紙だけを写し、モニターや回答ボタンを入力に混ぜません。

認定試験はMNISTの独立したテスト分割から出題します。これは同じ作業台での手書き数字認識の試作であり、AGIやMNIST全体の公式ベンチマークを実装するものではありません。

データ：[MNISTミラー（CVDF）](https://github.com/cvdfoundation/mnist)、[TensorFlowのデータ仕様](https://www.tensorflow.org/datasets/catalog/mnist)。同じ800枚は `python3 prototypes/seedlab-godot/tools/import_mnist.py` で再取得できます。通常の起動ではダウンロード不要です。

## OpenAIコーチ

コーチは学習する小さなNNとは別の役割です。`gpt-5.4-nano` のResponses APIへ、現在の成績・強化段階・購入候補と、ゲーム内の強化盤画像1枚（送信時256×256）を渡します。日本語の選択理由と次の目標を画面に表示します。

- 構造化出力で候補IDか「貯める」を返し、サーバーで再検証します。自由なコードの生成・実行は行いません。
- 初回の委任時と、その後24回以上の練習かつ30秒以上の間隔で相談。認定試験は相談間隔の回数に含みません。
- 出力最大400トークン、画像は低詳細。自動再試行や高額モデルへの切替はありません。
- 共通の `server/usage-policy.js` を使用。重複リクエストの合流・5分キャッシュ・同時2件を維持し、この試作は最大4回/分、20回/サーバー起動に抑えます。環境にそれより小さい上限があれば従います。失敗も回数に含まれます。アカウント全体の金額上限ではありません。
- 30Gを残して買える強化だけを候補にします。回答待ちに手動購入した場合は、古い段階の購入を取り消します。
- 停止後の遅れた回答は購入に使いません。通信・回答のエラーは明示し、委任を停止します。
- サーバーは `127.0.0.1:4873` のみで待受。ブラウザのOrigin付きリクエストを拒否します。キーは表示・保存・Godotへの転送をしません。
- ランチャーまたはゲームが起動したサーバーは、そのゲーム終了時に止まります。すでに動いていたサーバーは停止しません。

参照：[Responsesの画像入力](https://developers.openai.com/api/docs/guides/images-vision)、[構造化出力](https://developers.openai.com/api/docs/guides/structured-outputs)、[モデル仕様](https://developers.openai.com/api/docs/models/gpt-5.4-nano)。

## 保存・引き継ぎ

MNIST用の進行は `.local/seedlab-mnist.json` に自動保存（エクスポート版は `user://`）。数字用のNNを新しく育てます。旧ライト課題の `seedlab-3d.json` / `seedlab-new-garden.json` と旧2D版の `seedlab.json` はそのまま残し、異なる入力の学習済み重みを流用しません。

- `run-new-garden.command` / `-- --new-garden`：MNIST用の別セーブ `seedlab-mnist-new-garden.json` で育成。次回は続きを読み込みます。
- `-- --no-save`：保存を読まず、書かず、新しいNNで試遊。
- `-- --playtest`：MNISTの保存を読み、書き戻さずに試遊。
- 購入済みの操作、MNISTの学習済み重み・経験・G・メダルを保存。起動時の自動練習と委任はOFFです。

## 確認

```sh
node --test prototypes/seedlab-godot/bridge/server.test.mjs
./prototypes/seedlab-godot/run.command --headless --script tests/test_buttons.gd
./prototypes/seedlab-godot/run.command --headless --quit-after 3 -- --no-save
pnpm run check
```

カメラの実画像を取り直す場合：

```sh
./prototypes/seedlab-godot/run.command -- --vision-check=/tmp/seedlab-vision.json
./prototypes/seedlab-godot/run.command --headless --script tests/test_buttons.gd -- --fixtures=/tmp/seedlab-vision.json
```

`-- --capture=/tmp/seedlab.png` は起動後30フレームで画面を保存。通常画面でF12を押すと同じ場所に再保存します。検証結果は [VALIDATION.md](VALIDATION.md)。

## 素材・構成

`main.gd` が進行、`button_lab.gd` が報酬・強化・試験、`vision_brain.gd` がNN、`brain_monitor.gd` が机の常設表示、`openai_coach.gd` がローカル接続、`bridge/server.mjs` がOpenAI通信を担当します。

Blenderで制作した作業台・アーム・手先のGLBと、編集用の `assets/source/seedlab-workshop.blend` を同梱。別のBlenderシーンは保護しています。ボタン・照明・エフェクト・効果音はGodot内で生成します。

ユーザー指定のGodot試作のため、Vite / Three.js作品のHTML入口や作品カタログへの登録はありません。
