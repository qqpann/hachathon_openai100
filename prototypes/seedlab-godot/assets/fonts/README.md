# Japanese font for packaged builds

Noto Sans CJK JP Regular, from https://github.com/notofonts/noto-cjk/blob/main/Sans/OTF/Japanese/NotoSansCJKjp-Regular.otf . Licensed under the SIL Open Font License 1.1, included in OFL.txt. The font file is unmodified. Packaged games bundle this font so Japanese text renders on Windows and Linux without extra fonts; editor builds continue to use installed system fonts.
